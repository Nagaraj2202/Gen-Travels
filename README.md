# Gen-Travels

The Gen Travel Management System is a full-stack web application designed to simplify and improve the travel planning experience. It allows users to explore tourist destinations, discover travel packages, view hotel details, and manage bookings through a user-friendly interface. The project aims to make travel planning more convenient, organized, and accessible.
